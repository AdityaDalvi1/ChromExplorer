ChromExplorer 2.0.0 README
---------------------------

Changelog
---------

ChromExplorer 2.0.0

1.	Update for MTE30 (software registration and activation)

ChromExplorer 1.4.1

2.	New build system has been introduced
3.	All dependencies have been converted into the NuGet packages
4.	User can copy current peak list into the clipboard in the Wiley

Supported Operating Systems
---------------------------
ChromExplorer can be installed on the following operating systems:
Windows XP (x86) with Service Pack 3 - all editions except Starter 
Edition
Windows XP (x64) with Service Pack 2 - all editions except Starter 
Edition
Windows Vista (x86 & x64) with Service Pack 1 - all editions except 
Starter Edition
Windows 7 (x86 and x64)
Windows 8 (x86 and x64)
Windows Server 2003 (x86 & x64) with Service Pack 2
Windows Server 2003 R2 (x86 and x64)
Windows Server 2008 (x86 and x64) with Service Pack 2
Windows Server 2008 R2 (x64)

Hardware Requirements
---------------------
Computer that has a 1.6GHz or faster processor
1024MB RAM
3GB of available hard disk space
5400 RPM hard disk drive
DirectX 9-capable video card that runs at 1280 x 1024 or higher 
display resolution
DVD-ROM Drive

Software Requirements
---------------------
ChromExplorer requires the Microsoft .NET Framework 4.0 installed on 
your system to run the application. This can be obtained from the 
Microsoft Website 
http://www.microsoft.com/download/en/details.aspx?id=17851&WT.mc_id=MS
COM_EN_US_DLC_DETAILS_121LSUS007996

If your system does not have .NET 4.0 installed please download the 
file from the above link. To install, double click on the dotnetfx.exe 
and follow the instructions in the wizard.

Installation
------------
Run chrom_explorer-setup.exe or chrom_explorer-setup_x64.exe and 
follow the installation program instructions.
